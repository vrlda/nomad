# Nomad declared standards corpus.
#
# Each test is identified by its generated WPT variant prefix (e.g. url/url-constructor.any.html
# expands to its ?include=/?exclude= sub-variants). Expected status is per-platform:
#   PASS    - every subtest must pass on every supported platform.
#   FAIL    - a declared, understood gap. The exact expected-failing subtests are listed
#             as JSON-encoded indented lines beneath the test entry.
#   BLOCKED - the test cannot be executed on a platform (infrastructure limit); recorded
#             with the reason, not silently skipped.
#
# Format: <test-id> | <status> | <optional note>
# A FAIL entry must fail exactly on the listed subtests and pass everywhere else.
# The runner emits a deterministic JSON artifact per platform.
#
# Vendored-tree note: the upstream WPT snapshot ships both a "Streams" and a lowercase
# "streams" tree; the Servo manifest generator keys on the lowercase duplicate, so the
# Streams family is excluded from this corpus until the vendored tree is deduplicated.
